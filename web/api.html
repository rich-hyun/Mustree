제공 가능한 API

Mustree API 게이트웨이는 NFT, SBT, RWA, 토큰 정책, 브릿지, 거버넌스, 노드 관리 등 엔터프라이즈 Web3 전반을 아우르는 API를 제공합니다.

API 이름설명메서드엔드포인트주요 파라미터

메타데이터 업데이트온체인/오프체인 수정PUT/v1/nfts/metadatacontract, tokenId, metadataURI
